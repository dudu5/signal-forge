The Mission: A meta-tool for evolving how humans think and articulate perspective through structural reflection.

🔴 The Problem: Narrative Entropy
Most human communication is trapped in "Prose." Words are used to defend, obscure, or rationalize. When we stay in narrative, we cannot see the Structure of our own thinking. We get lost in the "leaves" of the tree and lose sight of the "branches" (logic) and "roots" (needs).

🟢 The Solution: The Structural Mirror
Signal Forge is a desktop-first environment designed to strip away narrative noise. It uses LLMs as a high-fidelity mirror to extract and refine the hierarchical structure of any input.

🔄 The Two Evolution Loops (The Core Genius)
Unlike static outliners, Signal Forge operates on two interconnected learning loops:

  L1: Structure Evolution
    Action: Select any node or branch in your hierarchy.
    Result: Prompt the LLM to refine, expand, or reorganize that specific section. You evolve the map of your current thought.

  L2: Prompt Evolution (The Perspective Library)
    Action: Iterate on the "Perspective Filters" (prompts) themselves.
    Result: You are not just building a better map; you are building a better compass. Users develop a library of refined "ways of seeing" that improve the quality of future extractions.

🛠 The Workflow
Content (Audio, PDF, Transcripts) → Perspective Filter (Prompt) → LLM Extraction → UI (Dynamic Outliner) → Selection-based Re-prompting → Refinement.

🏗 Initial Technical Goals
  I am seeking a collaborator to help build the "Industrial" workspace for this process:

  The Tree UI: A keyboard-centric, nested outliner (Dynalist style) that supports fluid "Zoom-in/Zoom-out" navigation.
  Perspective Engine: A system to manage and iterate on a "Prompt Library" where prompts are treated as first-class assets.
  Context-Aware LLM Bridge: Allowing the user to select a specific node and send only that branch + parent context to the LLM for L1 refinement.

🛠 Principles
  Structure over Narrative: Depth = Detail/Narrow Scope; Height = Broad/Overview.
  User-Driven Evolution: The LLM does not "hallucinate" content; it reflects and reorganizes the user's signal.
  Open Source & Data Sovereignty: The thinking process is sacred and must be owned by the user.
